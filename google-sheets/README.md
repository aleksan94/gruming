# Google Sheets как бэкенд

Сайт — статика. Данные читает и записи отправляет через Google Apps Script (Web App), привязанный к таблице.

    браузер ──GET──▶ Apps Script ──▶ листы «Мастера», «Услуги», «Записи на прием»
            ◀─JSON──                  (занятые слоты отдаются без имён и телефонов)
            ──POST─▶ Apps Script ──▶ новая строка в «Записи на прием»

## 1. Таблица

1. Создайте новую Google-таблицу.
2. **Расширения → Apps Script**, вставьте содержимое [Code.gs](Code.gs), сохраните.
3. Выберите функцию `setup` и нажмите **Выполнить** (разрешите доступ к таблице). Появятся три листа с заголовками.
4. Заполните «Мастера» и «Услуги». Быстрее всего импортом готовых примеров: на листе **Файл → Импорт → Загрузить**, выберите [seed/masters.csv](seed/masters.csv) или [seed/services.csv](seed/services.csv), «Заменить текущий лист».

Заголовки колонок менять нельзя: по ним код находит данные.

### Мастера

| Колонка            | Что писать                                                          |
| ------------------ | ------------------------------------------------------------------- |
| ФИО                | Уникально: по нему мастер связывается с записями                    |
| Должность          | «Старший грумер»                                                    |
| С кем работает     | `собаки`, `кошки` или `собаки и кошки`                              |
| Описание           | Короткое, для карточки                                              |
| Подробное описание | Для окна «Подробнее»                                                |
| Специализация      | Несколько пунктов: **по одному в строке** (Alt+Enter внутри ячейки) |
| График работы      | По интервалу в строке: `Пн–Пт 10:00–18:00`, `Сб 10:00–16:00`        |
| Фото               | Необязательно: ссылка на картинку. Пусто — заглушка                 |
| Цвет               | Необязательно: `peach`, `sky`, `butter`, `mint`, `green`            |

### Услуги

| Колонка                       | Что писать                                                                                     |
| ----------------------------- | ---------------------------------------------------------------------------------------------- |
| Название                      | Уникально                                                                                      |
| Длительность (мин)            | Число: `90`. По нему занимается нужное число часов в расписании мастера                        |
| Для кого                      | `собаки`, `кошки`, `собаки и кошки` (показывается как есть)                                    |
| Описание / Подробное описание | Как у мастеров                                                                                 |
| Что входит                    | Несколько пунктов, по одному в строке                                                          |
| Важно                         | Необязательно: заметка перед визитом                                                           |
| Стоимость                     | Число: `1800` (на сайте «от 1 800 ₽»)                                                          |
| Иконка                        | Необязательно: `drop`, `scissors`, `waves`, `comb`, `paw`, `sparkle`, `heart`, `clock`, `play` |
| Цвет                          | Необязательно, как у мастеров                                                                  |

### Записи на прием

Заполняется сайтом: дата и время, услуга, мастер, цена и длительность (берутся из листов, а не от браузера), имя, телефон, статус `Новая`. Чтобы **освободить слот**, поставьте в колонке «Статус» значение `Отменена` (или удалите строку). Остальные статусы, например `Подтверждена`, слот держат.

Колонки «Имя» и «Телефон» добавлены к вашему списку: без них администратору некому перезванивать.

## 2. Публикация Web App

1. В Apps Script: **Начать развертывание → Новое развертывание → Веб-приложение**.
2. Выполнять от имени: **Я**. У кого есть доступ: **Все**.
3. Скопируйте URL вида `https://script.google.com/macros/s/…/exec`.

После любого изменения `Code.gs` нужно **Управление развертываниями → Изменить → Новая версия**, иначе работает старый код. Правки данных в листах обновляются сразу.

Проверка: откройте URL в браузере, должен прийти JSON с `masters`, `services`, `busy`.

## 3. Сайт

    cp .env.example .env     # VITE_API_URL=<URL из шага 2>
    npm run build            # результат в dist/

Без `VITE_API_URL` сайт показывает демо-данные и никуда ничего не отправляет.

### Хостинг статики (бесплатно)

Во всех вариантах: команда сборки `npm run build`, папка `dist`, переменная окружения `VITE_API_URL`.

- **Cloudflare Pages** / **Netlify**: подключить репозиторий, указать команду, папку и переменную.
- **GitHub Pages**: переменная в _Settings → Secrets and variables → Actions → Variables_, деплой из `dist` через Actions. Пути в сборке относительные, подпапка вроде `/gruming/` работает.

`VITE_API_URL` попадает в код сайта и виден всем, это нормально. Секретов в проекте нет.

## Ограничения

- Apps Script отвечает за 1–3 с, поэтому каталог кэшируется в браузере, а свежие данные подменяют кэш.
- Два клиента не займут один слот: запись идёт под блокировкой, занятость проверяется на сервере повторно.
- Сервер не проверяет график мастера, только занятость, существование услуги и мастера, формат даты и телефона. Расписание контролирует интерфейс.
- Защиты от спама нет: это публичная форма, мусорные строки удаляются в таблице вручную.
- Квоты Apps Script (бесплатный аккаунт) для салона с запасом хватает.
